# X Poyo-Notification Jackpot (Pavlov's bird)

X(Twitter) の通知タブが未読状態になった瞬間に、パチンコの当たり演出のような七色発光を通知アイコンへ付与し、通知画面へ開くまでの速さをランク表示する Chrome 拡張です。

## 仕様

- `x.com` / `twitter.com` の通知タブを監視します
- 未読通知を検知すると、通知タブが七色に点滅しながら強く発光します
- 通知バッジの数字部分も別レイヤーで虹色発光し、拡大しながら強調表示されます
- 通知画面を開いた時点で、未読が点灯してからの経過時間を計測します
- ランクに応じて画面中央に派手な評価オーバーレイを表示します
- 計測状態は `chrome.storage.local` に保存するため、同一ブラウザ内の別タブ間でも引き継がれます

## ランク

- `SSS`: 1000ms 未満
- `SS`: 1000ms 以上 1500ms 未満
- `S`: 1500ms 以上 2000ms 未満
- `A`: 2000ms 以上 5000ms 未満
- `B`: 5000ms 以上 30s 未満
- `C`: 30s 以上 60s 未満
- `D`: 1min 以上 5min 未満
- `E`: 5min 以上 30min 未満
- `F`: それ以外

## ファイル

- `manifest.json`: Chrome Extension Manifest V3
- `content.js`: 通知タブ監視、経過時間計測、アニメーション表示

## 使い方

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このリポジトリのルートフォルダを選ぶ
5. X を再読み込みする

## 注意

- X 側の DOM 構造が大きく変わると、通知バッジの検知ロジックを調整する必要があります
- 未読検知は `data-testid` と `aria-label` の両方を使ったヒューリスティクスです
- 点灯したあと別タブで先に通知画面を開くと、その時点でランク確定します
